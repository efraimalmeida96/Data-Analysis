# 📊 Data Analysis Exercises

This repository contains a collection of data analysis exercises designed to practice and strengthen skills in **Python, Pandas, Matplotlib, NumPy, and exploratory data analysis (EDA)**.  
The exercises range from simple manipulations to more advanced statistical testing and visualization tasks.

---

## 🚀 Purpose
The goal of this repository is to:
- Practice real-world **data wrangling** and **cleaning**.
- Explore **descriptive statistics** and **visualization**.
- Apply **hypothesis testing** and **statistical reasoning**.
- Strengthen knowledge of **Python for data analysis**.
